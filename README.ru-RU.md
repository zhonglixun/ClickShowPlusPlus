# ClickShow 2.0

Инструмент украшения кликов мыши для Windows. Каждый клик — левый, средний, правый, X1 и X2 — раскладывает цветную волну прямо у курсора.

![Демонстрация](https://user-images.githubusercontent.com/1972649/122925974-f17ead00-d399-11eb-9c57-9b2f14dd5973.gif)

![Настройки](docs/screenshot-settings.png)

> Современная переработка [cuiliang/ClickShow](https://github.com/cuiliang/clickshow) (на основе 1.4.1). Спасибо оригинальному автору. Интерфейс и функции полностью переписаны; только Windows 10/11.

## Функции

### Волна клика
- Отдельные цвет и включение для всех пяти кнопок (левая/средняя/правая/X1/X2), с палитрой и шестнадцатеричным вводом;
- **8 тем оформления**: Классика / Неон / Карамель / Океан / Закат / Лес / Ягоды / Макарон — применение одним кликом;

![Темы](docs/theme-presets.png)

- **Длительность анимации** регулируется от 200 до 600 мс;
- **5 стилей распространения**: равномерно / замедление (естественное) / сильное замедление (вода) / лёгкий отскок / упруго;
- Двойной фон предпросмотра: сразу проверьте эффект на светлых и тёмных сценах.

### Светлый и тёмный профили
Светлое и тёмное оформления сохраняются отдельно (размер, цвета, длительность, стиль); автоматически следуют теме системы или фиксируются на одной.

### Точка мыши
Круглый индикатор, следующий за курсором; размер и цвет настраиваются, отдельное включение.

### Тишина
- **Автоскрытие в полноэкранном**: без эффектов, когда окно на переднем плане заполняет экран — игры и видео остаются чистыми;
- **Тишина по программам**: добавьте программы (ввод, обзор или захват переднего плана), чтобы скрывать эффект, пока они на переднем плане.

### Язык интерфейса
简体中文 / English / 日本語 / 한국어 / Español / Français / Deutsch / Português (Brasil) / Русский / Italiano. При первом запуске следует языку системы; меняется в настройках.

### Область уведомлений
- Левый клик по значку открывает настройки;
- Контекстное меню: открыть настройки / пауза волны / выход;
- Пауза действует мгновенно и восстанавливается без следов.

## Системные требования

Windows 10 1809+ или Windows 11 (x64). Среда выполнения включена — **устанавливать .NET не нужно**.

## Установка

1. Скачайте ClickShow-Setup-2.0.0.exe со страницы Releases этого репозитория;
2. Запустите мастер: поддерживается собственный путь установки (корень диска автоматически получает папку); ярлыки на рабочем столе и в меню «Пуск» опциональны;
3. Если запущена старая версия, установщик попросит её закрыть.

Портативная версия: скачайте ClickShow-2.0.0-portable.zip, распакуйте и запускайте — без установки; настройки лежат в %APPDATA%/ClickShow.

## Обновление с 1.x

- Старые настройки (`Документы/ClickShow.setting`) автоматически мигрируют при первом запуске в `%APPDATA%/ClickShow/setting.json` — цвета и параметры сохраняются;
- Светлый и тёмный профили начинаются с одинаковых значений;
- Установка поверх сохраняет все настройки и запись автозапуска.

## Сборка

```
dotnet publish ClickShow/ClickShow.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Установщик: скомпилируйте `installer/ClickShow.iss` с помощью [Inno Setup 6](https://jrsoftware.org/isinfo.php).

## Вопросы и ответы

- **Нет волны в полноэкранном режиме?** Работает «автоскрытие в полноэкранном» — отключите его в настройках;
- **«Пауза волны» в области уведомлений серая?** Не удалось установить мышиный хук (редко) — перезапустите приложение;
- **Запись автозапуска сломана после удаления?** Установщик удаляет запись автозапуска автоматически.
