# ClickShow++ 2.0.0

系统美化小玩具：每次点击鼠标，在光标处扩散一圈彩色波纹，让每一次点击都有存在感。

## 下载

- `ClickShow-Setup-2.0.0.exe` — 安装版：自定义安装路径、桌面/开始菜单快捷方式可选、覆盖升级保留配置
- `ClickShowPlusPlus-Portable-2.0.0.zip` — 便携版：解压即用，无需安装

## 功能

- 五键独立颜色与启用开关（左/中/右/X1/X2），支持取色器与十六进制精调
- 8 套主题预设：经典 / 霓虹夜行 / 糖果 / 海洋 / 夕阳 / 森林 / 莓果 / 马卡龙
- 动画时长 200–600 ms、5 种扩散样式（匀速 / 减速 / 强减速 / 回弹 / 弹性）
- 明暗双套外观，跟随系统主题自动切换
- 鼠标浮标（大小、颜色可调）
- 静默：全屏自动隐藏、指定程序前台静默（手动输入 / 浏览 / 抓取前台）
- 10 种界面语言，首次启动跟随系统语言
- 托盘菜单：打开设置 / 暂停波纹 / 退出

## 系统要求

Windows 10 1809+ 或 Windows 11（x64），自包含运行时，无需安装 .NET。

## 从 1.x 升级

首次启动自动迁移 `我的文档/ClickShow.setting` 到 `%APPDATA%/ClickShow/setting.json`，原颜色与设置保留。

Independent colors for five buttons, 8 color presets, adjustable duration and 5 easing styles, light/dark profiles that follow the system theme, fullscreen and per-program silence, 10 UI languages.
