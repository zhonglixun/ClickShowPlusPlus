# ClickShow++ 2.1.4

修复界面细节：切换语言后更新卡片文字不跟着变，以及控件上出现的虚线焦点框。

## 本次更新

- 更新卡片（标题、状态、按钮文字）在切换界面语言后立即刷新，不再停留在旧语言；
- 去掉控件的虚线焦点框，改为柔和的圆角描边焦点提示，键盘操作时依然能看出焦点位置。
