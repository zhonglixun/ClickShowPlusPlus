# ClickShow++ 2.1.5

补回界面重写时遗漏的三套主题预设，并让预设与取色器的改动同步到十六进制输入框。

## 本次更新

- 主题预设恢复为 8 套：经典默认 / 霓虹夜行 / 糖果 / 海洋 / 夕阳 / 森林 / 莓果 / 马卡龙，2.1 版界面重构时只放了前 5 套；
- 选择预设或从取色器选色后，右侧十六进制输入框立即同步新颜色（之前要切换配置或重启才刷新）；
- 设置界面截图更新为 2.1.5。
