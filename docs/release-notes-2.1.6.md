# ClickShow++ 2.1.6

界面大改造：自绘标题栏、可视化主题预设、鼠标键位图标、全新的标准调色器。

## 本次更新

- **自绘标题栏**：去掉系统标题栏，窗口按钮（最小化 / 最大化 / 关闭）融进界面右上角，标题区透明可拖动，双击最大化；最大化精确贴合工作区，不再出现黑边；
- **主题预设可视化**：8 套预设 + 自定义改成卡片，每张卡直接展示五个键位的配色，选中的卡片高亮描边，一眼对比；
- **鼠标键位图标**：左键 / 中键 / 右键 / X1 / X2 / 鼠标浮标都配了鼠标图形图标，高亮对应按键；
- **调色器重做**：饱和度-明度方块 + 色相条 + 透明度滑条 + 十六进制（支持 #RRGGBB 与 #AARRGGBB）+ RGB 三个数值框 + 常用色板，拖动即时预览。
