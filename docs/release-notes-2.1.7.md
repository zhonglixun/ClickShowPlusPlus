# ClickShow++ 2.1.7

键位图标重做、自定义预设实时同步、去掉多余的关闭按钮。

## 本次更新

- 键位图标换成完整鼠标轮廓：高亮对应按键区域（左/右半边、滚轮、侧键）；
- 侧键 X1/X2 改为同侧双键造型，均位于鼠标左侧，X1 高亮下方一颗、X2 高亮上方一颗；
- 鼠标浮标改用圆点图标，并实时显示当前的浮标颜色；
- 主题预设里的「自定义」卡片改为显示当前五键配色，取色后即时更新；
- 移除各设置页右下角多余的「关闭」按钮，关闭窗口用右上角的窗口按钮。
